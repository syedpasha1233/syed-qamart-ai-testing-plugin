# QA Mart AI Testing Plugin
One installable plugin that makes any tester productive on QA Mart.

## Install
Install from this repo: `https://github.com/syedpasha1233/qamart-ai-testing-plugin`
(VS Code: Chat > Install Plugin from Source, or the install method shown in class.)

## What's inside
- Instructions: locators-and-naming, no-hard-waits
- Prompts: /smoke-test, /review-test
- Skills: checkout-test-design, bug-report
- Agents: planner, healer, reviewer (read-only)
- MCP: Playwright, filesystem (no secrets or tokens)
- Hooks: block `.only` edits, lint after edits

## 60-second demo
1. Install the plugin. 2. Run `/smoke-test` in Agent mode. 3. Watch Playwright MCP check login, add to cart and checkout.
